# Changelog

All notable changes to **SolarWise AI** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- Complete solar rooftop yield modeling engine with shadow-free area calculations.
- Integrated Google Gemini AI (`@google/genai`) for customized scenario reasoning.
- Indian State Subsidy Matrix (2026) under PM Surya Ghar Muft Bijli Yojana.
- Real-time interactive financing calculator with dynamic EMI and 25-year cashflow analytics.
- Serverless Netlify API endpoints for zero-cold-start cloud execution.
- Comprehensive technical documentation and MIT open source license.

### Fixed
- Sanitized numeric input validation to prevent NaN in EMI calculations.
- Wired interactive sliders for real-time scenario updates.
